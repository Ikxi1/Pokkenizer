# Pokkenizer

This thing tokenizes any ASCII text on Linux.

### Current features:

- Tokenize a string with custom delimiters (delimiters are deleted)
- Save tokens in memory

### Planned features:

#### In the near future:
- "Persistent delimiters" that are delimiters but also tokens
- Outputting tokens as file (what format? json?)

#### In the far future:
- SIMD and multi-threading features
- GLIBC independant
- Platform independant
